# Appalachia Tracker

A web-first Fallout 76 companion tracking app scaffold.

## Current scaffold includes
- React + TypeScript + Vite foundation
- Tailwind theme tokens for retro-terminal inspired styling
- App shell with desktop sidebar and mobile bottom navigation
- Primary routes: Dashboard, Collections, Map Reference, Notes, Data, Settings
- Typed catalog and progress models
- Zod schema validation for seed content
- Dexie (IndexedDB) local database schema
- Versioned JSON seed files for Bobbleheads, Magazines, and Holotape Games
